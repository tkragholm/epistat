# epistat-testkit

Test helpers for numerical code: tolerances in absolute, relative and ULP
terms, fingerprints of exact bit patterns, a check that results do not depend
on the number of threads, ratios of deviations to tolerances, a `SplitMix64`
generator for test problems, a marker for undefined values, checks that an entry point refuses empty, NaN, mismatched and unsorted input with an `Input` error and that a crate's error codes are unique, and loading of reference values written by R's
`jsonlite`, with its `NA`, `NaN` and `Inf`.
